Project 1: Smart CLI Chatbot
Days 1–2 LLM API Python Streaming Multi-turn memory
What you'll build

A terminal chatbot that remembers everything you say, streams replies word-by-word, and lets you set its personality via a system prompt. By the end you'll understand how LLMs actually "remember" conversations — and why it's not magic.

Step-by-step plan
1
Setup & your first API call ~30 min
Install the SDK, set your API key, send a single message and print the response. Understand what a completion actually returns.
2
Add multi-turn memory ~45 min
Build a messages list that grows with every exchange. Learn why the model has no real memory — you're sending the full history every time.
3
Add streaming output ~30 min
Switch from waiting for the full response to printing tokens as they arrive. Makes the chatbot feel alive and responsive.
4
System prompt & persona ~30 min
Add a system prompt that defines the bot's personality. Experiment with different personas and see how dramatically behavior changes.
5
Commands, token counter & polish ~45 min
Add /clear, /help, /persona commands. Show a live token count so you understand context window limits. Make it feel like a real tool.
Key concepts
Messages array
How user/assistant turns are structured and sent to the model
System prompt
The hidden instruction that shapes the model's entire personality
Streaming
Receiving tokens as they generate instead of waiting for the full reply
Tokens & context window
The unit of text LLMs process and the limit on how much they can "see"
Temperature & params
Controls randomness — low = focused, high = creative
API keys & .env
Safely storing secrets so you never accidentally commit them

Stuck? Common problems
AuthenticationError / invalid API key
Usually means the .env file isn't loading. Click to debug.
Bot forgets everything each message
You're not appending to the messages list correctly. Click to see why.
Streaming prints all at once
